Local AI

github.com/DiogoGLAlmeida/local-ai-stack

A personal assistant that runs on my gaming PC (an RX 7900 XTX with 24 GB). The models run locally with Ollama, so my email and calendar are never sent to ChatGPT or any other cloud AI. It's only for me: it is not a public service and nobody else's account is connected to it.

What it does day to day

  • Every morning it writes a note in Obsidian with my calendar, tasks, the emails that matter, new vulnerabilities in software I use, and the news.
  • Once a week it sorts the people and services that email me into Gmail labels and creates the filters. It runs in dry-run first, so I can check the plan before anything changes.
  • A small inbox page shows which emails actually need a reply, and scores LinkedIn job alerts against what I'm looking for.
  • An agent can use Gmail, Calendar, Drive, Obsidian and the web through MCP tool servers running in Docker.

A few things I learned building it

  • The 9B model once invented a calendar event that didn't exist. Anything that uses tools now runs on a 27B model instead.
  • Small models sometimes answer "false" as text instead of false, and in JavaScript that counts as true. Now every answer the model gives is checked in code before it's used.
  • I left out Gmail's permission to send email on purpose. The worst it can do is put a label in the wrong place.

Ollama, Docker Compose, n8n, Open WebUI, MCP, JavaScript, PowerShell. The Google sign-in it uses is covered by the privacy policy.

Evidence to ATT&CK

github.com/DiogoGLAlmeida/evidence-to-attack

This started as IRONSIGHT, my project for the postgraduate course. It reads incident evidence, like threat reports, emails and Windows event logs, and maps what happened to MITRE ATT&CK techniques using a local model. Every mapping has to quote the line of evidence it's based on, so a person can check it.

Right now I'm working on the first part: reading the different file types (text, HTML, PDF, EML, EVTX) into one format. After that comes the mapping itself, then which logs and detection rules would catch each technique.

Python, MITRE ATT&CK, local LLM. MIT license.
